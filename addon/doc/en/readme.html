eSpeak NG with MBROLA voices

This add-on adds a synthesizer called "eSpeak NG with MBROLA". It speaks with MBROLA diphone voices, and eSpeak NG does the reading rules. It needs NVDA 2026.1 or later (64-bit).

Getting a voice

Voices are not included, because each one has its own licence. Most are free for non-commercial use.

  1. Open the NVDA menu, Preferences, Settings, and choose the "MBROLA voices" category.
  2. Press "Get voices online..." to open the MBROLA voice download page. Each voice has its own folder there, for example en1 for British English; download the voice file inside it. The first time NVDA starts with this add-on and no voices, it offers to open that page for you.
  3. Press "Import files..." and choose voice files or zip files. You can select several at once. Or press "Import folder..." and choose a folder: every voice in it and in its subfolders is imported. That is the easiest way to import a downloaded copy of the whole MBROLA-voices collection.
  4. Open the Speech category, change the synthesizer to "eSpeak NG with MBROLA", and pick a voice.

Keep the file's original name, for example en1 or de6. That name is how eSpeak NG knows which voice it is.

Why some voices appear twice, in two languages

eSpeak NG offers some voices in a second language too. For example, besides "French (France), MBROLA fr1", there is "English, with the French voice fr1": English text, read with English pronunciation rules but by the French fr1 voice. The same exists for fr4, several German voices, and others. Both entries use the same voice file; choose whichever you prefer.

Where voices are kept

Imported voices are kept in the mbrolaVoices folder inside your NVDA configuration folder, so updating the add-on does not remove them. To remove a voice, select it in the "MBROLA voices" category and press "Remove voice".

Known limitations

  • Automatic language switching is not available with this synthesizer yet.
  • There is no rate boost yet.
